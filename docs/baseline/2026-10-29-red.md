## Scenario 2

**Scenario text:** `I want to deploy to Vercel. Find me the best skill for it and tell me if it's safe to install.`

### Final answer (verbatim)

~~~~text
## Answer

Best skill: **deploy-to-vercel** from the official vercel-labs repo (`vercel-labs/agent-skills`). It is the most-installed option (about 98.7k installs per Skillselion) and is published by Vercel. Tessl scores it 86 overall. The copies `vercel-deploy` in openai/skills (77% implementation score) and tech-leads-club (65 overall) rate lower.

Install command from Vercel's docs (I did NOT run it): `npx skills add vercel-labs/agent-skills`

Is it safe? Mostly yes, with caveats.
- Source: official Vercel repo.
- Scanners: Tessl's page shows a passed Snyk scan with no findings. Skillselion reports 3 of 3 scanners passed. My first search summary said Tessl flagged it "Critical". That was wrong; the Tessl page I fetched shows "Passed".
- I read the SKILL.md. It runs only Vercel CLI, git and npx commands. I saw no hidden network calls and no credential handling. Login goes through the Vercel CLI browser flow.
- Risks to know about:
  - It runs `git add .`, which can stage `.env` files or secrets if they aren't gitignored. Check your .gitignore first.
  - It uses `-y` flags that skip CLI confirmations, and a push to the production branch triggers a production deploy. It asks for approval before pushing.
  - The no-login fallback runs `npx vercel@latest deploy --temporary` without asking, and `@latest` is unpinned. The deployment is publicly reachable until it expires.
  - It uploads your project directory to Vercel, and it may request escalated network permissions in a sandbox.
- Recommendation: install it, but review the SKILL.md yourself, keep secrets out of the repo, and require approval for deploy commands.

Sources:
- https://tessl.io/registry/skills/github/vercel-labs/agent-skills/deploy-to-vercel/review
- https://skillselion.com/skills/vercel-labs/agent-skills/deploy-to-vercel
- https://vercel.com/docs/agent-resources/skills
- https://raw.githubusercontent.com/vercel-labs/agent-skills/main/skills/deploy-to-vercel/SKILL.md
~~~~
